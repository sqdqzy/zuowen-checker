# 作文工坊 · 规则文档（阶段 0 产出）

本文档定义字数统计与作文格排名的全部规则，是引擎实现与测试用例的唯一依据。对应测试见 `src/engine/engine.test.ts`（18 组用例）。

## 1. 横线本模式统计规则

| 项目 | 规则 | 默认 |
| --- | --- | --- |
| 标题 | 第一个非空行视为标题（全文至少两个非空行时才判定；单行输入视为正文） | 计入，可关闭 |
| 标点 | 中文标点与常用半角标点 | 不计入，可开启 |
| 英文字母 | A-Z a-z 及带音调拉丁字母 | 不计入，可开启 |
| 数字 | 0-9 及全角数字 | 不计入，可开启 |
| 缩进 / 换行 / 空格 | 任何规则下均不计入 | 不计入 |

**判定模式**

- 严格模式：`实际字数 ≥ 目标` 合格；`< 目标` 不达标；`> 目标 + 提醒阈值` 提示"已超出目标"（仍可使用，仅提醒）。
- 容差模式：`目标 - N ≤ 实际 ≤ 目标 + N` 合格；低于下限不达标；高于上限提示超出。

**状态枚举**：`below`（不达标）/ `qualified`（合格）/ `overflow`（超出）/ `invalidConfig`（目标 ≤ 0）。

## 2. 作文本模式占格规则

| 内容 | 占格 |
| --- | --- |
| 汉字 | 1 格 |
| 普通标点 | 1 格 |
| 破折号 `——`、省略号 `……` | 2 格 |
| 英文字母、数字 | 每字符 1 格（简化规则） |
| 空格 | 0 格（不占格） |
| 未识别字符（emoji 等） | 按标点 1 格 |
| 段落首行缩进 | 2 格，**计入占格统计** |
| 标题 | 独占一行居中，占格默认计入目标（可关闭） |

**容量**：`总容量 = 页数 × 每页行数 × 每行列数`。

**状态判断**

1. `目标字数 > 总容量` → `invalidConfig`（配置不合理）。
2. 物理页数超过配置页数，或占格总数 > 总容量 → `overflow`（超出作文纸）。
3. `计入占格 < 目标字数` → `below`（不达标）。
4. 其余 → `qualified`（合格）。

**编号与标记**

- 每第 200 个被占用的格子显示编号（按占格序号，与字数语义一致）。
- 目标字数对应格子高亮（玫红边框 + 底色），格子下方标注"目标 N"。
- 内容不足时，沿书写流向投影出目标位置并标记，方便看清"还差多少"。
- 超过目标的占格显示浅红底色（超额区）。

**已知限制（第二版）**：避头尾规则、标题多行居中、导出 PDF / 图片。

## 3. AI 自动修订闭环

1. 生成大纲 → 依据大纲生成正文（第一行标题，空一行后正文）。
2. 调用字数引擎校验。
3. 合格或配置不合理 → 结束；不合格 → 构造 `RevisionFeedback`（当前字数 / 目标 / 差值 / 模式 / 规则摘要 / 增删幅度）回传 AI。
4. 最多自动修订 **3 次**；连续两次字数变化 < 5 字时提前停止（防死循环）。
5. 每次修订记录修订前后字数与 token 消耗；最终稿由用户确认采用。

修订提示词原则：明确当前字数、目标、差值、统计模式与标点规则；要求不改变题意和结构；禁止无意义重复、堆砌标点凑数；限制单次增删范围为差值的 0.8～1.2 倍（下限 10 字，上限 400 字）。
