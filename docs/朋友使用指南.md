# 作文工坊 · 使用说明（给朋友版）

一个纯本地运行的网页小工具：统计作文字数、按作文本排版预览，还能接入 AI 帮你写作文并自动控制字数。

## 一、怎么打开

**方式 1：离线版（推荐，发个压缩包就能用）**
1. 解压 `作文工坊-离线版.zip` 到任意文件夹
2. 双击里面的 `index.html`，用 Chrome / Edge 打开
3. 完事。不需要联网、不需要安装任何东西

**方式 2：局域网**
- 你的电脑和朋友的手机/电脑连同一个 Wi-Fi
- 朋友浏览器打开 `http://192.168.10.102:5180`（需要你这边的服务器开着）

**方式 3：在线链接**
- 部署后发给朋友一个网址即可（需要时可帮你部署）

## 二、手动校验字数（不需要任何配置）

1. 打开页面，在左侧文本框粘贴作文原文（或点“载入示例”先试试）
2. 选模式：
   - **横线本**：普通横线纸，按“字数”统计
   - **作文本**：标准作文格纸，按“占格数”排版
3. 右侧设置：目标字数（默认 800）、作文格的行列数/页数
4. 右侧实时显示：
   - 实际字数 / 占格数
   - 状态：不达标 / 合格 / 超出纸张
   - 作文本模式下有格子预览图，玫红色标记目标字数位置

默认规则：标题计入字数，标点/英文/数字不计，段落缩进不计。

## 三、AI 帮你写作文（可选）

1. 切到“AI 生成”标签
2. 填 API Base URL 和 API Key（任何 OpenAI 兼容接口，如 DeepSeek、Moonshot、OpenAI）
3. 点“获取模型列表”，选一个模型
4. 输入作文题目和要求，点“生成大纲”→“生成正文”
5. 工具自动校验字数，不合格会自动把结构化反馈发回 AI 修订，最多 3 次
6. 修订记录表格里能看到每次字数变化和 token 消耗
7. 满意了点“采用此稿并继续编辑”，回到手动校验页继续改

## 四、手机上用

页面自动适配手机竖屏。作文格预览下方有“缩小/放大”按钮控制格子大小。

## 五、注意事项

- API Key 只存在你自己浏览器的 localStorage 里，不经过任何服务器，但**不要在公用电脑上保存**
- AI 生成的作文建议通读一遍再交，它控制字数很准，但内容要自己把关
