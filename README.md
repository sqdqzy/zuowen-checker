# 作文工坊 · 作文字数校验与 AI 作文生成工具

两套引擎 + AI 闭环的 MVP：

- **字数统计引擎**：横线本模式（可配置标题 / 标点 / 英文数字是否计入，严格与容差两种判定）+ 作文本模式（按格子占格统计，支持分页）。
- **作文格排版引擎**：SVG 按页渲染格子矩阵，每 200 格编号，目标字数位置高亮标记，超额区标注，超出作文纸自动溢出到新页并警告。
- **AI 生成**：填入 OpenAI 兼容 API（Base URL + Key）即可获取模型列表，输入题目与要求后自动生成大纲和正文，调用字数引擎校验，不合格时把结构化结果回传 AI 自动修订（最多 3 次，带防死循环），全程展示每次修订的字数变化与 token 消耗，最终稿由用户确认采用。

## 快速开始

```bash
npm install
npm run dev        # 开发预览（默认 http://127.0.0.1:5180）
npm test           # 引擎单元测试（18 组）
npm run build      # 类型检查 + 生产构建（输出 dist/）
```

## 使用说明

### 手动校验（不依赖 AI）

1. 顶部切换到「手动校验」。
2. 在「统计模式与规则」中选择 **作文本** 或 **横线本**，设置目标字数与各项规则。
3. 在「作文原文」中粘贴或输入文字（可点「载入示例」体验）。
4. 右侧实时显示统计结果、状态徽章与预览：
   - 作文本：格子矩阵按页渲染，玫红标记目标字数位置，浅红为超额区。
   - 横线本：逐字标注计入（绿）/ 不计入（灰），标题有标识。

### AI 生成

1. 切换到「AI 生成」，填写 API Base URL（如 `https://api.openai.com/v1`，未带 `/v1` 会自动补全）与 API Key。
2. 点「获取模型列表」拉取模型；失败时可手动填写模型名（如 `deepseek-chat`）。
3. 输入作文题目与写作要求，点「生成大纲与正文」。
4. 流程：大纲 → 正文 → 校验 → （不合格）自动修订，最多 3 次；每次修订记录字数变化与 token 消耗。
5. 点「采用此稿并继续编辑」写入手动校验模式继续修改；历史记录本地保存最近 20 条，可随时恢复。

## 规则摘要

- 横线本：标题默认计入（可关）；标点、英文、数字默认不计（可开）；缩进与换行永不计。
- 作文本：汉字 / 标点 1 格，破折号与省略号 2 格，英文数字每字符 1 格，每段首行缩进 2 格计入；标题居中且默认计入目标。
- 状态：不达标 / 合格 / 超出 / 配置不合理（目标 > 容量）。
- 详见 [`docs/rules.md`](docs/rules.md)（含 18 组测试用例清单）。

## 安全与风险提示

- API Key 仅保存在浏览器 localStorage，不上传任何服务器；纯网页版直连 API 仍存在暴露风险，请勿在公用电脑保存 Key。
- 浏览器直连可能受 CORS 限制：获取模型失败时可手动填写模型名；建议优先使用允许浏览器跨界的 OpenAI 兼容服务。
- AI 修订提示词已限制无意义扩写与堆砌标点凑字，但生成内容仍需人工把关。
